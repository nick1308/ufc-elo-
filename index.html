How It Works

The methodology behind the UFC Elo Engine by NBAtrev.

Base Formula

Every fighter starts at 1000. After each fight, ratings update using the standard Elo formula:

E(A) = 1 / (1 + 10^((R_B - R_A)/400)) R_new = R_old + K × (S - E) S = 1 (win) 0 (loss) 0.5 (NC/Draw)

The larger the rating gap, the smaller the gain for the favourite — and bigger the loss if upset.

K-Factor Adjustment

Uses a dynamic K-factor. Newer fighters have higher K (ratings move fast); veterans stabilise over time. Prevents long-career fighters being over-penalised late in their careers.

K = base_k / sqrt(fights_completed)

Data Source

  • Scraped from ufcstats.com via custom Python scraper
  • Every UFC event from UFC 1 (Nov 1993) to April 2026
  • 7,000+ individual fights in chronological order
  • 2,688 unique fighters across all weight classes

Limitations

  • No weight-class separation — all divisions share one pool
  • No inactivity decay in current version
  • Pre-UFC career not factored in
  • High-volume careers accumulate Elo over time
  • Engine by NBAtrev · GitHub

⟳ How to Update

This file is a static snapshot from April 12, 2026. UFC events happen almost every weekend. Here's how to get fresh rankings anytime:

1
Go to github.com/NBAtrev/UFC-Elo-Engine and clone or download the repo. It contains the full scraper + Elo engine.
2
Run python ufcstatswebscraper.py — this hits ufcstats.com and pulls every fight result up to today into a CSV.
3
Run python UPDATEDufceloengine.py — processes all fights chronologically and outputs updated Elo CSVs.
4
Replace the const DATA = [...] array in this HTML file with the new fighter data. Ask Claude to rebuild the file with the new CSVs.
⚡ Tip: The repo owner (NBAtrev) periodically pushes updated CSVs to GitHub after big events. Check current_fighters_elo.csv and k_factor_adjust_current.csv for the latest numbers before re-running the scraper yourself.
